# Примеры

Папка `templates` подходит для начального открытого профиля. Импортируются только непосредственные файлы `.json`/`.jsonc`. Заголовки директивы заблокированы: `null` удаляет заголовок даже при наличии общего значения. Оригиналы не изменяются.

Папка `closed` содержит `sys.user.id` и требует закрытого профиля: начальный профиль — 10 пользователей на 60 секунд. Каждый пользователь ожидает завершения запроса вместе с повторами. Начальный открытый профиль — 100 RPS на 60 секунд; повторы выключены. Чтобы проверить цепочку повторов, задайте общий максимум 2 и направьте запросы на собственный локальный тестовый endpoint, возвращающий 503, 503, 200. Все три попытки используют одинаковое тело.

Токены раскрываются только в строковых значениях тела. Токен на всю строку сохраняет собственный тип, а внутри текста становится текстом. `\\{{sys.uuid}}` в JSON передаёт буквальный токен без обратной косой черты. Для повторов одного запроса сохраняются UUID, время и случайные значения; новый запрос получает новые значения.
